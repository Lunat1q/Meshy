Hotkeys help

General

  • Spacebar = add new point
  • Enter = pop point
  • S = show stats

Rendering settings

  • L = toggle lines
  • T = toggle triangles
  • P = toggle points

Color

  • R = toggle red channel
  • G = toggle green channel
  • B = toggle blue channel

Color modes

  • 1 = gradient colors
  • 2 = random colors
  • 3 = gradient animated circles

Animation:

  • A = toggle animation
  • { (Left bracket) = increase trail time animation
  • } (Right bracket) = decrease trail time animation
  • + = increase points speed
  • - = decrease points speed
